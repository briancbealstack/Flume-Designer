Export to SolidWorks

All three routes build the same geometry; pick whichever suits how you work.
.sldcrv — no scripting. Insert → Curve → Curve Through XYZ Points, then browse to the file. Set the document units to match your selection above first.
.bas — a VBA module in plain text. A .swp is a binary VBA project container, so a text file renamed to .swp will not open. Instead: Tools → Macro → New, save an empty macro, then in the VBA editor use File → Import File. Run BuildCurve, or BuildSketchSpline for an editable 3D sketch.
.vbs — double-click, no macro editor. Builds the curve feature using scalar API calls only.
Exit sketch mode before running either script. If Windows blocks a downloaded script, right-click → Properties → Unblock.
